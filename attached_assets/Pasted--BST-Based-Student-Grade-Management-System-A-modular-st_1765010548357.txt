
BST–Based Student Grade Management System
A modular, structured digital grading workflow system using MySQL for persistent data and a Binary Search Tree engine for optimized searching, ordering, and academic demonstration of data structure operations.

1. FEATURES (FULL LIST)
A. Admin Features
1. Student & Subject Management
Add, edit, delete students (Name, Student ID, Email).


Add, edit, delete subjects (code, title).


Bulk student upload (CSV).


Bulk subject upload (CSV).


Merge duplicate student records.


Lock or archive old academic terms.


2. Grade Management
Create assessments per subject (Quizzes, Exams, Projects).


Set weight, maximum score, and category for each assessment.


Record grades for individual students.


Bulk grade encoding via CSV.


Edit and delete grade entries.


Automatic weighted grade computation.


Grade history (previous versions per student).


3. BST Operations & Visualization
Build BST for:


Student ID


Final grade


Assessment score


View real-time visual BST representation (SVG/Canvas).


Show step-by-step BST operations:


Insert


Search


Delete


In-order / Pre-order / Post-order traversal


Export BST as JSON.


Auto-balance mode (optional AVL/RBT demonstration).


Educational mode (show comparisons, rotations, pointer changes).


4. Reports & Analytics
Per-student grade summary (all subjects).


Per-subject distribution graphs.


Assessment-level statistics (mean, median, top/bottom performers).


Exportable CSV/PDF grade sheets.


Automated ranking per subject (using BST in-order output).


Report generation per class, subject, term.


5. User & Role Management
Admin accounts (full access).


Teacher accounts (restricted by subject or class).


Optional: Viewer/Auditor role (read-only).


View activity logs (who edited what).


Role-based permissions for grade editing.


6. System Administration
Backup/restore database.


Reset academic term (archive data).

Configure grading formulas.


Import/export entire academic dataset.



B. Teacher Features
View assigned classes and subjects.


Encode or update grades per assessment.


View computed final grades in real-time.


View student performance summaries.


Run BST visualizations for their own classes.


Generate downloadable grade sheets.


Receive system alerts (missing data, invalid grades, inconsistencies).



C. Student Features
Login via Student ID.


View personal profile and enrolled subjects.

3. SYSTEM FLOW (DETAILED)
1. User Authentication
Admin/Teacher/Student logs in → credentials validated → role-specific dashboard loaded.
2. Student & Subject Setup
Admin imports or manually creates students and subjects → system validates entries → DB stores records.
3. Assessment & Grade Entry
Teacher creates assessments → specifies weights → encodes grades manually or via CSV → DB stores grade rows → system auto-generates updated final grades.
4. BST Construction
Admin/Teacher selects:
Build BST by student ID


Build BST by grade


Build BST by assessment score


System fetches relevant data → constructs BST in-memory → returns:
Node relationships


Insert paths


Traversal logs


Search steps


This is used for both:
Search optimization


Visualization/academic demonstration


5. BST Search Flow
User searches for student or grade → server constructs BST → executes search() → returns:
Node found


All traversal steps


BST subset for visualization


6. Reports Generation
User selects reporting type → server fetches MySQL data → optional BST traversal for sorting → exports:
Grade sheets


Subject analytics


Class ranking


PDF summaries


7. Term Archiving
Admin closes academic term → system moves records to archive tables → clears active tables → maintains access for history viewing.
